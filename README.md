# YYC Halal Eats – put it on your Galaxy S22 Ultra

The app needs to live on a web address (free) so Chrome can install it.

## Easiest: GitHub Pages (free, ~5 minutes)
1. On github.com, create a new **public** repository called `eatsmap`.
2. Click **Add file → Upload files** and upload everything in this folder (keep the `images` folder).
3. Go to **Settings → Pages**, set Source to **Deploy from a branch**, branch `main`, folder `/ (root)`, Save.
4. After a minute, open `https://YOUR-USERNAME.github.io/eatsmap/` in **Chrome on the phone**.
5. Chrome menu (⋮) → **Add to Home screen → Install**. It now opens full-screen like a normal app.

## Using it
- **+** button: add a restaurant (address lookup, "I'm here now", or tap a spot on the map).
- **Menu → Paste a list**: one per line `Name | Food type | Address | Offer`.
- Chips at the top filter by food type; **Deals today** shows only offers valid today
  (offers can be set to certain weekdays and an end date).
- **Directions** opens Google Maps.
- Data stays on your phone. Use **Menu → Save a backup file** now and then.
